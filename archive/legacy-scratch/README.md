# Legacy Scratch (archived 2026-09-25)

as historical artifacts per the prior worktree-ownership decision, moved out
of the repository root for clarity. They are NOT part of the test suite
(pytest collects only `trading-platform/tests`) and are excluded from lint.

Canonical equivalents live in `trading-platform/tests/` (e.g. phase 7
failure-injection coverage in `tests/unit/test_monitoring_recovery.py` and
`tests/unit/test_oms_reconciliation.py`).
